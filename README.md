# CPU Logic Pet — исходный код

Тамагочи для рабочего стола Windows: Лоджи и Ева. Одна программа на C# (WPF, .NET Framework 4),
без сторонних библиотек — собирается компилятором, который уже есть в Windows 10.

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Получится `CPULogicPet.exe` в этой же папке. Visual Studio не нужна.

## Файлы

| Файл | Что это |
|---|---|
| `Program.cs` | Весь код программы |
| `build.ps1` | Скрипт сборки |
| `phrases-loji.txt`, `phrases-eva.txt` | Фразы девушек по разделам |
| `dialogs.txt` | Диалоги Лоджи и Евы |
| `tama-open.png`, `tama-closed.png` | Лоджи в окне: глаза открыты / закрыты |
| `cut-open.png`, `cut-closed.png` | Лоджи без фона |
| `eva-open.png`, `eva-closed.png` | Ева в окне |
| `eva-cut-open.png`, `eva-cut-closed.png` | Ева без фона |
| `tray.png`, `pet.ico` | Значок в трее и иконка exe |

Картинки и тексты зашиваются внутрь exe. Тексты при первом запуске выкладываются рядом с exe
и дальше читаются оттуда — их можно править без пересборки. Если во встроенной версии появился
новый раздел, программа сама допишет его в конец файла рядом с exe, не трогая остальное.

## Как устроен код

- `Program` — точка входа, один экземпляр программы (Mutex), вспомогательные функции для файлов.
- `CharacterDef` — всё, чем отличаются девушки: имя, заголовок окна, цвета, картинки, звуки,
  символы вместо сердечек. Чтобы добавить третью девушку, достаточно описать её здесь,
  добавить картинки и файл фраз и создать её окно в `Director.Start`.
- `Settings` — настройки каждой девушки в `%APPDATA%\CPU-Logic\pet-<id>.ini`.
- `Phrases` / `Dialogs` — чтение фраз и диалогов из текстовых файлов.
- `Sounds` — звуки синтезируются в памяти при запуске (WAV из синусоид), файлов звуков нет.
- `Director` — общий для обеих: значок в трее, проверка АФК (`GetLastInputInfo`), очередь реплик,
  диалоги, реакция на появление второй девушки, ревность.
- `PetWindow` — окно одной девушки: рамка «от руки», моргание, облачко с репликой,
  сердечки, перетаскивание, меню, режим без фона.

## Ключи запуска для проверки

- `--dialog-now` — сразу начать диалог (если на экране обе).
- `--selftest` — Ева уходит и возвращается, потом Лоджи гладят 6 раз подряд (Ева ревнует).
